# 마감 때 돈이 안 맞을 때
> 검수 전 초안 — RAG 담당(영민) 검수 뒤 이 줄을 지웁니다. 이름 · 번호 · 금액 · 회사는 전부 가짜입니다.

## 1. 먼저 다시 세기
- 준비금 10만 원(가짜)을 뺐는지 먼저 확인해요. 큰 돈부터 권종별로 다시 세고, 가능하면 다른 사람이 한 번 더 세요.
- 계산대가 여러 대면 계산대마다 따로 맞춰요.
- 카드가 안 맞으면 금액보다 건수부터 맞춰요. 단말기가 몇 대인지, 비대면 결제나 취소 건이 있었는지 확인해요.

## 2. 흔한 원인 찾아보기
- 거스름돈 착오, 현금인데 카드 버튼을 누름(또는 반대), 카드 승인 취소 누락, 처방 본인부담금을 고친 뒤 수납에 반영 안 됨, 앱 결제 같은 비대면 결제가 단말기 합계에서 빠짐.
- 10만 원 이상 현금 결제에 현금영수증이 나갔는지도 봐요. 손님이 원하지 않았으면 5일 안에 무기명으로 발급할 수 있어요 (소득세법 시행령 제210조의3).

## 3. 그래도 안 맞으면 — 기록하고 약국장에게 넘기기
- 날짜, 계산대 번호, 금액, 남음 또는 모자람, 찾아본 원인, 마감자 이름을 적어요.
- 도우미에게 차액을 말하면 약국장에게 넘기고 티켓 번호를 드려요. 처리 기준은 약국장만 보는 규정에 있어요.
- 다음 날 약국장이 정산표와 함께 확인해요. 결과는 "내 문의" 화면에서 볼 수 있어요.

## 4. 하면 안 되는 것
- 내 돈으로 메우기, 남는 돈 따로 챙기기는 하지 않아요. 원인을 못 찾게 되고, 차액을 월급에서 빼는 것도 법으로 막혀 있어요 (근로기준법 제43조).
- 청구를 여러 번 다시 보내기(중복 접수), 손님 결제를 마음대로 취소하기, "얼마까지는 괜찮다"고 스스로 정하기도 하지 않아요.
