# 접수 건 확인 안내

## 1. 접수 번호 읽기
- 접수 번호는 R-와 숫자 네 자리예요 (예: R-1001). 도우미가 이관하면 티켓 번호가 따로 나와요.
- 번호를 모르면 "내 문의" 화면에서 찾아요. 질문에 번호를 같이 쓰면 상태를 바로 알려 드려요.
- 번호 없이 "제 건 어떻게 됐어요?"라고 물으면 번호를 먼저 여쭤봐요.

## 2. 상태의 뜻
- 접수됨: 담당자가 아직 보지 않았어요. 처리 중 · 약국장 확인 중 · 약사 확인 대기: 담당자가 보고 있어요. 처리 완료: 끝났어요.
- 상태가 하루 넘게 그대로면 담당자에게 직접 말하거나 도우미에게 다시 물어봐 주세요.
- 같은 내용으로 새로 접수하지 않아도 돼요. 같은 요청을 두 번 보내도 티켓은 하나만 생겨요.

## 3. 내 건만 보이는 까닭
- 접수 건에는 이름, 연락처, 손님 정보가 들어 있어서 본인 건만 보여 드려요. 남의 번호를 물으면 "권한 없음"으로 답해요.
- 약사와 약국장은 약사 화면에서 이관된 건을 봐요. 도우미에게 남의 건을 대신 물어도 상태와 연락처를 알려 드리지 않아요.
- 가족이나 동료의 건이 궁금하면 그 사람이 직접 묻거나 담당자에게 물어봐 주세요.

## 4. 연락처는 가려서 보여 줘요
- 답에 나오는 전화번호와 메일은 가운데를 가려요 (예: 010-****-1101, h***@example.com).
- 티켓, 알림, 기록에도 연락처를 그대로 남기지 않아요. 연락처를 바꾸려면 약국장에게 말해 주세요.
- 접수 시스템이 느리면 기다리게 하지 않고, 지금은 확인이 어렵다고 먼저 알려 드려요.
