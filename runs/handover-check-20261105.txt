# 인수인계 서버 저장 — 실제 VM 증빙

- 일시: 2026-11-05 14:30:57 +0900
- 대상: https://aio-t3.isitsoft.kr
- 입장 코드: `$TEAM3_ENTRY_CODE` (파일에는 쓰지 않음)
- 시험: 남기기 → 다른 사람(정민재) 조회 → 보임 → 확인(done) → 다시 조회 null
- 당시 열린 티켓 12건이 서버에서 자동 첨부됨
- 저장소: PostgreSQL — 응답 `at`이 마이크로초 + `+00:00` 표기(`PgStore`). 메모리 저장소는 `+0900` 형식이라 구분됨

## 0) 시작 상태 — 확인 안 한 인수인계 조회 (이서준)

```bash
$ curl -s -H "X-Entry-Code: $TEAM3_ENTRY_CODE" -H "X-User: %EC%9D%B4%EC%84%9C%EC%A4%80" "https://aio-t3.isitsoft.kr/api/admin/handover"
```

HTTP 200

```json
{
  "item": null
}
```
