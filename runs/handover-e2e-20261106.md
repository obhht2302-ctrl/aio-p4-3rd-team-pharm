1. **확인 안 한 옛 인계가 다시 뜸**: API는 '확인 안 한 마지막 1건'을 줌 → 11/5 17:19 이서준 인계(#7)가 확인 안 된 채 남아 있어, 오늘 것(#8)을 확인하면 #7이 다시 보임. 시연 데이터 문제(어제 시험 흔적) + 동작 정의(최신을 확인하면 이전 것도 닫을지)는 API 담당(병훈) 판단 → 리드가 형에게 보고함.
