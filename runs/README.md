# 시험 기록 — 전체 목록

> **한눈에**
> - 다정약국 업무 도우미(약국 직원 · 어르신 질문을 n8n 워크플로우가 받아 문서로 답하거나 약사 · 약국장에게 넘기는 시스템, [README](../README.md))를 시험한 기록입니다.
> - 이 폴더에는 팀 VM에서 돌린 시험 결과 파일이 전부 들어 있습니다. 시나리오 시험은 `tools/flow.py test`, 응답 시간은 `tools/flow.py bench`로 돌렸습니다.
> - **기존 성적 = 11/6 최종 회귀**(기능 동결 버전)입니다. **11/9 재확인**은 동결 뒤 결함 두 가지(화면 안내 문구가 실제로 넘겨받는 사람 · 긴급도와 맞지 않던 것, WF-12 답 문장에 다른 접수 번호가 섞이던 것)를 고친 버전으로 같은 절차를 다시 돌린 것이고, 결과가 같았습니다. 두 날 모두 공통 20/20 × 3, 팀 24/24 × 3, 세 갈래 7/7 × 3, 장애 3/3 × 3입니다.
> - '× 3'은 회차 3번이고, 회차마다 앞의 숫자(예: 20/20)가 나왔다는 뜻입니다. 3절 표는 파일 하나 = 회차 하나라서 '× 3' 없이 적었습니다.
> - 정식 회차는 **회차마다 접수 기록 · 캐시를 지우고(`flow.py ops --reset`) 1번씩, 3회**입니다. 초기화 없이 연속 3번 돌리면 앞 회차 접수가 남아 있어서 같은 질문이 '중복 요청'으로 판정되고 56/60이 나옵니다. 이 기록은 참고로만 남겼습니다([실행 결과서](../docs/EXECUTION-RESULT.md) 4절 사례 1).
> - 숫자 해석과 실패 사례는 실행 결과서 3 · 4절에 있습니다.
