## 4. 인덱스 및 메타데이터

| 항목 | 값 |
| --- | --- |
| 컬렉션 · 메모리 키 이름 | `pharm_kb_v1_all` · `pharm_kb_v1_owner` (`<도메인>_<용도>_v<버전>_<권한>`) |
| 버전 · 전환 방법 | 메모리 키는 노드에 글자로 둠. 버전을 올릴 땐 `team3-index`의 `Index settings` · `Store all` · `Store owner`와 `team3-search`의 `KB settings` · `Search all` · `Search owner`를 같이 `pharm_kb_v2_*`로 바꿈 → 색인 → 검색 전환. 롤백은 같은 자리를 v1로 되돌리고 재색인 (메모리 저장소라 이전 버전이 n8n 재시작에 남지 않음) |
| 메타데이터 | `doc`, `title`, `section`, `chunk`, `access_level`, `kb_version`, `type` |
| 검색 전 필터 | 권한별 메모리 키: `access_levels`에 `owner`가 없으면 owner 키를 검색하지 않음 (WF-05) |
| 검색 후 처리 | `top_k × 2`개를 가져와 같은 `doc+section` 중복 제거 → 점수 내림차순 → `top_k`개. `access_level: owner` 청크는 owner 권한이 없으면 한 번 더 버림. `type`으로는 거르지 않음 (공통 문서를 놓치지 않게, 정렬은 본체). `SCORE_MIN` 미만은 본체가 뺌. 빈 질문은 `evidence: []` |
| 파티션 | 권한별 키 2개 (작은 규모의 파티션) |
